## Aula 7

### Contagem crescente

Crie um programa que receba um número inteiro N e imprima todos os números
de 0 até N, em ordem crescente. Considere N maior ou igual a zero.

### Números entre dois valores

Crie um programa que receba dois números inteiros e imprima todos os números
entre eles, incluindo os valores informados. Considere que o primeiro número
será menor que o segundo.

### Primeiros números pares

Crie um programa que receba um número inteiro positivo N e imprima os N
primeiros números pares, considerando o zero como um número par.

### Contagem decrescente

Crie um programa que receba um número inteiro N e imprima todos os números
de N até 0, em ordem decrescente. Considere N maior ou igual a zero.

### Tabuada

Crie um programa que receba um número inteiro e imprima sua tabuada de
multiplicação de 1 a 10.

### Fatorial

Crie um programa que receba um número inteiro N, maior ou igual a zero, e
calcule seu fatorial. Considere que o fatorial de zero é igual a 1.

### Positivo, negativo ou zero

Crie um programa que receba números inteiros continuamente. Para cada número
informado, exiba se ele é positivo ou negativo. Quando o usuário digitar zero,
exiba a quantidade de números recebidos, desconsiderando o zero, e encerre o
programa.

### Validação de senha

Crie um programa que solicite uma senha ao usuário. Caso a senha esteja
incorreta, exiba "ACESSO NEGADO" e solicite novamente. Repita o processo até
que a senha correta seja informada, exibindo "ACESSO PERMITIDO".

### Números pares, exceto múltiplos de 6

Crie um programa que receba dois números inteiros e imprima todos os números
pares entre eles, exceto aqueles que sejam múltiplos de 6. Considere que o
primeiro número será menor que o segundo.

### Média de números positivos

Crie um programa que receba números inteiros continuamente. Os números
positivos devem ser considerados para o cálculo da média, enquanto os negativos
devem ser ignorados. Quando o usuário digitar zero, encerre a leitura e exiba
a média dos números positivos informados.

### Média de cinco números pares

Crie um programa que receba números inteiros até que cinco números pares
tenham sido informados. Os números ímpares devem ser ignorados. Ao final,
calcule e exiba a média dos cinco números pares.

### Validação de data

Crie um programa que receba um número inteiro representando um mês do ano
(1 a 12) e, em seguida, um dia. Caso o dia seja inválido para o mês informado,
solicite um novo dia até que seja informado um valor válido. Considere
fevereiro com 28 dias.
