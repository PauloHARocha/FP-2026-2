## Aula 8

### Contagem com for

Crie um programa que receba um número inteiro N, maior ou igual a zero, e
imprima todos os números de 0 até N utilizando for.

### Números ímpares entre dois valores

Crie um programa que receba dois números inteiros e imprima todos os números
ímpares entre eles, incluindo os limites quando forem ímpares. A impressão
deve começar pelo menor número informado.

### Consoantes de uma string

Crie um programa que receba uma string e imprima todas as consoantes
presentes nela.

### Contagem da letra A

Crie um programa que receba uma string e informe quantas vezes a letra 'a'
aparece nela.

### Soma de números em um intervalo

Crie um programa que receba dois números inteiros e calcule a soma de todos
os números entre eles, incluindo os valores informados. Considere que o
primeiro número será menor que o segundo.

### Média de números em um intervalo

Crie um programa que receba dois números inteiros e calcule a média aritmética
de todos os números entre eles, incluindo os valores informados. Considere
que o primeiro número será menor que o segundo.

### Fatorial

Crie um programa que receba um número inteiro N, maior ou igual a zero, e
calcule seu fatorial utilizando for. Considere que o fatorial de zero é igual a 1.

### Somatório de números ímpares

Crie um programa que receba um número inteiro N, maior ou igual a zero, e
calcule a soma de todos os números ímpares entre 0 e N.

### Número perfeito

Crie um programa que receba um número inteiro positivo e determine se ele é
perfeito. Um número é considerado perfeito quando a soma de seus divisores
positivos, excluindo o próprio número, é igual ao número informado.
